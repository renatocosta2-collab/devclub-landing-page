# 🚀 DevClub Landing Page

Landing page desenvolvida como projeto de Front-End durante minha formação no **DevClub**.

O projeto foi construído com foco na prática de **HTML5 semântico, CSS3, JavaScript e responsividade**, aplicando conceitos de organização de código e experiência do usuário.

## 📌 Sobre o projeto

A proposta foi desenvolver uma landing page moderna para apresentar o ecossistema DevClub, seus conteúdos, áreas de formação e mentores.

Além da estrutura visual, o projeto utiliza interações em JavaScript e efeitos visuais para proporcionar uma experiência mais dinâmica ao usuário.

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Particles.js

## ✨ Funcionalidades

- Layout responsivo
- Navegação entre as seções
- Área de apresentação dos conteúdos
- Apresentação dos mentores
- Carrossel de conteúdo
- Efeitos e animações
- Efeito de partículas no background
- Botão de acesso à Área do Aluno
- Adaptação para diferentes tamanhos de tela
